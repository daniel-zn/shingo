Three languages

english · 日本語 · français
EN

English runs the interface

Every action, label and number. If someone has to read it to use the app, it's in English.

Protected
日本語

Japanese adds texture

Vertical captions along edges, seal stamps and outlined display kanji. Use one Japanese moment per screen at most. It is never the only label on a control.

認証受信箱圏外
Fr.

French is the aside

Italic footnotes, dates, taglines and pull quotes. Use it once per screen at most, usually in the quietest spot.

×3

All three only once

Stack the same line in all three languages in one place only: the lock screen, splash or about page. Repeating the stack elsewhere weakens it.
