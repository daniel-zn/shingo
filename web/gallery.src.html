Signal Kit

A UI kit that rebuilds the sage, coral and stripe poster style from code. Everything on this page is drawn with CSS and vector glyphs. There are no bitmaps. The same parts ship as SwiftUI views in ios/.

[ assessment / open-design brutalist-skill ]

The repo skill is a 9 KB text prompt with no assets, shapes or code. It also contradicts this poster. It bans rounded corners, but the poster is built on stadium pills and rounded X marks. It allows one light or dark background per screen, but the poster puts sage slabs on an ink ground. Its accent is hazard red #E61919, not coral #ff715e.

Its spirit is still useful: grids, mono telemetry text and technical framing. So this kit is built from scratch. It has its own tokens, generated glyphs, web components and SwiftUI shapes, all measured off the reference.

Nested stadium pill

Three stacked capsules and a slot line. Proportions: band 18% of height, core 15%, slot 3%. Doubles as a hero, card, scrubber or progress bar. .pill · NestedPill()

Rounded X

The union of two crossed stadiums. It comes outlined, solid or faint. Use it for status, done or rest days, close and error. #g-x-line · RoundedX()

Stripe field

A soft repeating gradient with a 6 pt period. Facets are extra layers with a different angle and a clip-path. .tex .facet · StripeField (Canvas)

Slab and coral diagonal

Screens split into an ink top and a sage bottom along one diagonal. The coral band is the only accent surface. .slab .band · DiagonalSlab

Chamfer frame

A hairline outline with two cut corners. It frames fields, groups and ID cards. .chamfer · ChamferRect()

Instrument badges

The topo disc, record rings, radar fan, barcode lines, crosshair and arrows. All are generated, so they recolor with tokens. assets/svg/*
